## 📖 About

**Vexora Studio** is a modern agency-style landing page designed with a strong focus on elegant layouts, responsive design, and a premium user experience.

The project demonstrates how professional websites can be created using only **HTML5** and **CSS3**, without relying on frameworks or JavaScript.

---

## ✨ Features

- 🎨 Premium and modern UI
- 📱 Fully responsive design
- 📐 CSS Grid & Flexbox layouts
- 🔤 Clean typography
- 💼 Professional agency landing page
- 📬 Newsletter section
- ⭐ Testimonials section
- 🦶 Elegant footer design
